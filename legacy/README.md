# Старый прототип на Python (не используется)

`cablesend_python_prototype.py` — самая первая версия идеи, написанная до Rust-ядра.
Она **не является частью приложения**: Flutter её не вызывает, скрипты сборки её не трогают,
документация на неё не ссылается.

Почему вынесена сюда (это были реальные конфликты):
- **Другой протокол.** Здесь передача по HTTP, а в рабочем ядре — свой кадровый протокол
  поверх TCP (`src/proto.rs`). Две версии несовместимы между собой.
- **Пересечение портов.** Прототип слушает **53320**, а рабочее ядро использует этот порт
  для туннеля «телефон → ПК» (`adb reverse`). Если запустить одновременно, они мешают друг другу.
- **Другое обнаружение.** Прототип ищет соседей на порту 53321 и своим форматом сообщений,
  рабочее ядро — на 53318 форматом `CABLESEND2`.
- **Внешняя зависимость** `psutil`, которой больше нигде в проекте нет.

Файл оставлен только как справка: в нём есть полезные наработки по определению типа
кабеля по имени сетевого интерфейса. Если он не нужен — удалите папку `legacy/`.
Рабочее ядро: `src/`. Приложение: `app/`.
